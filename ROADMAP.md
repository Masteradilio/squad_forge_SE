# LocalForge OS Roadmap

## Current — V5 open-source readiness

- remove evaluation-domain behavior from the runtime;
- make benchmark preflights and routing evidence real and reproducible;
- publish a standards-based Python package and first-run path;
- establish contributor and security governance;
- reduce pipeline, API, and frontend monoliths;
- validate hybrid routing on unseen repositories.

## Next — public alpha

- plugin contracts for providers, sandboxes, runners, and evaluators;
- reproducible comparative benchmark packs;
- frontend test coverage and accessibility baseline;
- signed release artifacts and upgrade notes;
- contributor-facing architecture documentation.

## Later — team control plane

- multi-repository policy management;
- remote runners and centralized audit retention;
- role-based access controls and organization-wide budgets;
- routing optimization based on verified task outcomes.

Roadmap items are targets, not promises. Quality, security, and evidence gates take priority
over dates.

# Support

LocalForge is alpha software maintained on a best-effort basis.

- Use GitHub Discussions for setup questions and design conversations when enabled.
- Use GitHub Issues for reproducible bugs and approved feature proposals.
- Use private vulnerability reporting for security issues.

For a useful bug report, include the LocalForge version, operating system, Python/Node
versions, command exit code, final summary, failing test names, and only the relevant
traceback excerpt. Remove credentials and private source before posting.

Commercial support and compatibility guarantees are not currently offered.

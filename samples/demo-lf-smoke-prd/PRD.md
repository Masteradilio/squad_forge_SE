# LocalForge Smoke PRD

Build a tiny Python utility module that:

1. Computes the arithmetic mean of a list of floats.
2. Computes the median of a list of floats.
3. Computes Pearson correlation between two float lists.
4. Provides a CLI flag parser to choose operation.
5. Includes unit tests covering the happy path with deterministic inputs.

The implementation must be pure Python (no numpy), have full type hints,
and use only the standard library.

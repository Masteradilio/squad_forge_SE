# E2E Evidence Registry

Reports in this directory are preserved to explain architectural decisions. They are not all
current proof of product quality or savings.

| Artifact | Evidence status | Current use |
| --- | --- | --- |
| `V4_ONLY_BENCHMARK_REPORT.md` | Historical; V5 rerun required | Explains the V4 routing change |
| `V3_ONLY_BENCHMARK_REPORT.md` | Historical | Explains the V3 baseline |
| `POMODORO_BENCHMARK_REPORT.md` | Historical | Captures a prior product exercise |
| `HP12C_*` reports | Historical | Records the local-only failure analysis |
| `V2_V3_*` reports | Historical | Records a comparative attempt |

A report becomes current reproducible evidence only when its V5 manifest, sanitized inputs,
artifact hashes, acceptance commands, and independent human review are available. See
[`../benchmarks/METHODOLOGY.md`](../benchmarks/METHODOLOGY.md).

# LocalForge Historical V3 Pilot Record

> Status: historical evidence only — not a current comparative benchmark result.

This document preserves the reported V3 pilot outcome for audit history. Its disposable
workspace, database pricing snapshots, exact provider responses, and independent acceptance
evidence are not present in the current checkout. It must not be used to claim a verified
cost reduction, quality parity, or repeatable product advantage.

The pilot reported five planned tasks reaching `PR_READY` and a modeled cost comparison against
API-only alternatives. `PR_READY` is pipeline state, while the cost figures were calculated
from historical pricing snapshots rather than a same-workload, multi-lane rerun.

## What remains useful

- The pilot motivated contract-first routing and a persistent cost ledger.
- It identified the need to distinguish local work, paid work, deterministic validation, and
  human acceptance.
- It is a starting point for the V5 benchmark contract rather than proof that contract passed.

## Current evidence standard

V5 requires the same unseen task to run through frontier-only, economy-API-only, local-only,
and hybrid lanes with the same starting commit and acceptance tests. A publishable result must
include the evidence manifest, artifact hashes, actual provider/model attribution, elapsed time,
retries, human intervention, and independent human acceptance.

[`MASTER_BACKLOG_V5.md`](MASTER_BACKLOG_V5.md) for the current contract.

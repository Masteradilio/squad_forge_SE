# Clean-Room Notes

LocalForge OS is an original clean-room reimplementation inspired by public agent orchestration patterns.

Reference repositories may be studied for behavior, architecture, and edge cases, but implementation agents must not copy source code, schemas, prompts, tests, unique filenames, UI layouts, or internal protocols.

Primary concept inspirations:

- DeerFlow: long-horizon runtime, subagents, sandbox, skills, memory, context engineering.
- SwarmForge: role-based engineering workflow, worktrees, durable handoffs, QA gates.
- Multica: issues, local daemon, task lifecycle, agents as teammates, workspaces.
- Paperclip: governance, heartbeats, budgets, audit, goal ancestry.
- Ollama: local OpenAI-compatible model gateway.

All LocalForge code, schemas, tests, prompts, and UI must be original.

# Community Code of Conduct

We want Squad Forge SE discussions and collaboration to be technically rigorous, welcoming,
and safe.

Contributors must:

- discuss ideas and code without personal attacks or harassment;
- respect privacy, licenses, and security disclosure boundaries;
- provide evidence for technical and benchmark claims;
- accept constructive review and correct mistakes transparently;
- avoid discriminatory, threatening, or sexually explicit conduct.

Maintainers may edit, hide, or remove content and restrict participation when behavior puts
people, projects, or systems at risk. Report conduct concerns privately to the maintainer.
Enforcement decisions should explain the violated rule while protecting reporter privacy.

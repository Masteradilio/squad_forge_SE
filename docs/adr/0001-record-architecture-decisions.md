# ADR 0001 — Record Architecture Decisions

Status: Draft

## Context

LocalForge OS will make many architectural decisions while implementing the PRD and backlog.

## Decision

Use lightweight Architecture Decision Records in `docs/adr/` for decisions that affect architecture, safety, runtime behavior, storage, or public APIs.

## Consequences

Implementation agents should add short ADRs when making non-trivial decisions instead of asking broad clarification questions.
